준비는 끝났습니다. 이제 클로드 데스크탑에서 방금 받아 온 폴더를 열고, 클로드에게 첫 질문을 던져 봅니다.

## 클로드 코드 열기

1. 클로드 데스크탑 앱을 실행합니다.
2. 왼쪽 사이드바에서 **Code**를 선택합니다.
3. **Open folder**(폴더 열기)를 눌러 앞 단계에서 클론한 폴더를 고릅니다. 문서 폴더 안에 있는, 저장소 이름과 같은 폴더입니다.

## 권한 승인하기

폴더를 처음 열면 **이 폴더의 파일을 읽고 고쳐도 되는지** 묻는 화면이 나옵니다. 클로드 코드는 허락 없이 파일을 건드리지 않기 때문에 거치는 절차입니다.

내가 방금 만든 폴더가 맞는지 경로를 확인하고 승인합니다. 모르는 폴더가 떠 있다면 승인하지 말고 폴더를 다시 고르세요.

## 첫 질문 던지기

아래쪽 입력창에 한국어로 그냥 물어보면 됩니다. 명령어를 외울 필요는 없습니다.

```
이 프로젝트에 어떤 파일이 있는지 알려줘
```

클로드가 폴더를 살펴보고 파일 목록과 각각이 무슨 역할인지 설명해 줍니다. 답이 돌아왔다면 클로드 코드가 정상적으로 붙은 겁니다.

## 여기서부터

이제부터는 "무엇을 만들고 싶은지"를 말하면 됩니다. 예를 들면 이런 식입니다.

```
README에 이 프로젝트가 뭘 하는 건지 한 문단으로 적어줘
```

클로드가 고칠 내용을 먼저 보여 주고, 적용할지 물어봅니다. 마음에 안 들면 그대로 말하면 됩니다 — **되돌리는 것도 대화로 합니다.**
