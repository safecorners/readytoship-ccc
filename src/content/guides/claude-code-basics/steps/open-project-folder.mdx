준비는 끝났습니다. 방금 받아 온 폴더를 클로드 코드로 열어 봅니다.

1. 클로드 데스크탑 앱을 실행합니다.
2. 왼쪽 사이드바에서 **Code**를 선택합니다.
3. **Open folder**(폴더 열기)를 눌러 앞 단계에서 클론한 폴더를 고릅니다. 문서 폴더 안에 있는, 저장소 이름과 같은 폴더입니다.

고른 폴더의 이름이 깃허브에서 만든 저장소 이름과 같은지 한 번 더 확인하세요. 엉뚱한 폴더를 열면 다음 단계에서 다시 걸립니다.

## 폴더가 어디 있는지 모르겠다면

`git clone`을 실행했던 자리에 만들어집니다. 터미널에서 아무것도 옮기지 않았다면 보통 사용자 폴더 바로 아래입니다. 파일 탐색기(윈도우)나 Finder(맥)에서 저장소 이름으로 검색해도 됩니다.
