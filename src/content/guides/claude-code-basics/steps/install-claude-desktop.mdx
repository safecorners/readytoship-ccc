클로드 코드는 클로드 데스크탑 앱 안에서 돌아갑니다. 먼저 앱부터 깔아 둡니다.

## 내려받기

1. [claude.ai/download](https://claude.ai/download)에 들어갑니다.
2. 쓰는 운영체제에 맞는 버튼을 누릅니다. 사이트가 알아서 골라 주지만, 다르게 보이면 직접 고르면 됩니다.
   - 윈도우는 `.exe` 파일
   - 맥은 `.dmg` 파일. 애플 실리콘(M1 이상)과 인텔 맥의 파일이 다릅니다. 잘 모르겠으면 화면 왼쪽 위 사과 메뉴 → **이 Mac에 관하여**에서 칩 이름을 확인하세요.

## 설치하기

내려받은 파일을 두 번 눌러 실행합니다.

- **윈도우** — 설치 프로그램이 뜨면 안내대로 넘어갑니다. "알 수 없는 게시자" 경고가 나오면 **추가 정보 → 실행**을 누릅니다.
- **맥** — 창이 열리면 클로드 아이콘을 **Applications 폴더 위로 끌어다 놓습니다**. 그 다음 런치패드나 응용 프로그램 폴더에서 실행합니다.

## 로그인하기

앱을 처음 열면 로그인 화면이 나옵니다. 구글 계정이나 이메일로 로그인하세요. 계정이 없으면 이 화면에서 바로 만들 수 있습니다.

로그인하고 대화 화면이 보이면 이 단계는 끝입니다. 아직 클로드 코드를 쓰는 건 아니고, 그릇을 준비한 셈입니다.
