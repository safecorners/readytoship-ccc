Git은 코드의 변경 이력을 남기는 도구입니다. 깃허브에서 프로젝트를 가져오려면 반드시 있어야 합니다.

## 내려받기

[git-scm.com/downloads](https://git-scm.com/downloads)에 들어가 운영체제를 고르고 설치 파일을 받습니다.

## 설치하기

- **윈도우** — 설치 중에 선택지가 여러 번 나오는데, **전부 기본값 그대로 두고 Next만 눌러도 됩니다.** 마지막에 Install을 누르고 기다립니다.
- **맥** — 이미 깔려 있는 경우가 많습니다. 아래 확인 명령을 먼저 쳐 보고, 버전이 안 나올 때만 설치하세요. 확인 창이 뜨면서 개발자 도구 설치를 물어보면 그대로 설치하면 됩니다.

## 설치됐는지 확인하기

터미널(윈도우는 PowerShell)을 새로 열고 확인 명령을 실행합니다.

`git version 2.51.0` 처럼 버전이 찍히면 성공입니다. 숫자는 달라도 괜찮습니다.

명령을 못 찾는다는 오류가 나오면, **터미널 창을 완전히 닫았다가 다시 열고** 한 번 더 해 보세요. 설치 직후에는 이미 열려 있던 창이 새 프로그램을 알아보지 못합니다.
