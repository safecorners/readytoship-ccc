아래쪽 입력창에 한국어로 그냥 물어보면 됩니다. 명령어를 외울 필요는 없습니다.

```
이 프로젝트에 어떤 파일이 있는지 알려줘
```

클로드가 폴더를 살펴보고 파일 목록과 각각이 무슨 역할인지 설명해 줍니다. 답이 돌아왔다면 클로드 코드가 정상적으로 붙은 겁니다.

## 여기서부터

이제부터는 "무엇을 만들고 싶은지"를 말하면 됩니다. 예를 들면 이런 식입니다.

```
README에 이 프로젝트가 뭘 하는 건지 한 문단으로 적어줘
```

클로드가 고칠 내용을 먼저 보여 주고, 적용할지 물어봅니다. 마음에 안 들면 그대로 말하면 됩니다 — **되돌리는 것도 대화로 합니다.**
