깃허브는 코드를 올려 두는 곳입니다. 여기에 빈 저장소를 하나 만들어 두면, 앞으로 만들 것들이 담길 자리가 생깁니다.

## 계정 만들기

계정이 없다면 [github.com](https://github.com)에서 **Sign up**을 눌러 가입합니다. 이메일 인증까지 마쳐야 저장소를 만들 수 있습니다.

## 저장소 만들기

1. 오른쪽 위 **+** 버튼 → **New repository**를 누릅니다.
2. **Repository name**에 영문 이름을 적습니다. 띄어쓰기 대신 하이픈을 쓰세요. 예: `my-first-project`
3. **Public**과 **Private** 중에 고릅니다. 연습용이라면 **Private**이 마음 편합니다. 나중에 언제든 바꿀 수 있습니다.
4. **Add a README file**에 체크합니다. 저장소가 완전히 비어 있으면 다음 단계에서 가져올 게 없습니다.
5. 아래쪽 **Create repository**를 누릅니다.

## 주소 복사해 두기

만들어진 저장소 화면에서 초록색 **Code** 버튼을 누르고, **HTTPS** 탭의 주소를 복사합니다. `https://github.com/...`로 시작해 `.git`으로 끝나는 주소입니다.

이 주소는 바로 다음 단계에서 씁니다. 창을 닫지 말고 두세요.
