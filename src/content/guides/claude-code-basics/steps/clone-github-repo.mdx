클론은 깃허브에 있는 저장소를 내 컴퓨터로 통째로 복사해 오는 일입니다.

## 받아 둘 위치 정하기

터미널(윈도우는 PowerShell)을 열고, 프로젝트를 모아 둘 폴더로 이동합니다. 딱히 정해 둔 곳이 없다면 문서 폴더면 충분합니다.

```
cd Documents
```

## 클론하기

클론 명령어를 복사한 뒤, `https://...` 부분을 앞 단계에서 복사해 둔 **내 저장소 주소로 바꿔** 실행합니다.

처음 실행하면 깃허브 로그인을 물어볼 수 있습니다. 브라우저 창이 열리면 **Authorize**를 눌러 승인하세요.

## 확인하기

`Cloning into '내저장소'...` 하고 몇 줄이 지나간 뒤 아무 오류가 없으면 끝난 겁니다. 폴더가 실제로 생겼는지 봅니다.

```
cd 내저장소
```

경로가 바뀌면 성공입니다. **이 폴더가 앞으로 클로드 코드로 열 프로젝트 폴더입니다.** 어디에 있는지 기억해 두세요.
