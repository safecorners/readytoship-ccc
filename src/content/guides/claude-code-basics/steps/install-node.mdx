Node.js는 자바스크립트를 컴퓨터에서 실행해 주는 프로그램입니다. 클로드 코드와 앞으로 만들 프로젝트가 이 위에서 돕니다.

## 내려받기

[nodejs.org](https://nodejs.org)에 들어가 **LTS** 라고 적힌 쪽을 받습니다. LTS는 오래 지원되는 안정판이라는 뜻입니다. 옆에 있는 최신 버전은 고르지 마세요.

## 설치하기

받은 파일을 실행하고 안내대로 넘어갑니다. 여기도 기본값 그대로 두면 됩니다.

## 설치됐는지 확인하기

터미널(윈도우는 PowerShell)을 **새로 열고** 확인 명령 두 개를 차례로 실행합니다.

`v22.20.0`, `10.9.3` 처럼 버전이 두 번 찍히면 성공입니다.

## 오류가 났을 때

### 윈도우 — 실행 권한 오류

PowerShell에서 `npm --version`을 쳤을 때 아래처럼 **실행 권한(Execution Policies)** 이야기가 나오는 경우가 있습니다.

```
이 시스템에서 스크립트를 실행할 수 없으므로 ... 파일을 로드할 수 없습니다.
```

윈도우가 기본적으로 스크립트 실행을 막아 둔 탓입니다. 세 번째 명령어를 복사해서 실행하고, `Y`를 눌러 확인하세요. 그 다음 `npm --version`을 다시 치면 버전이 나옵니다.

이 명령은 **지금 로그인한 사용자 계정에만** 적용됩니다. 컴퓨터 전체 설정을 건드리지 않습니다.

### 명령을 못 찾는다고 나올 때

터미널 창을 완전히 닫았다가 새로 열고 다시 해 보세요. 그래도 안 되면 컴퓨터를 재시작한 뒤 확인합니다.
