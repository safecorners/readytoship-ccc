## Purpose

학습자가 어디까지 진행했는지를 로그인 없이 브라우저에 보존하고, 진행 상황을 사이트 여러 화면에 일관되게 노출한다. 여러 세션에 걸쳐 진행되는 설치 튜토리얼에서 "어디까지 했더라"를 없애는 것이 목적이다.

## ADDED Requirements

### Requirement: 완료 상태 보존

시스템은 학습자가 완료 표시한 체크 단위를 브라우저에 보존해야 한다(SHALL). 보존된 상태는 페이지를 새로고침하거나 사이트를 떠났다 돌아와도 유지되어야 한다(MUST). 계정 생성이나 로그인을 요구해서는 안 된다(MUST NOT).

상태는 브라우저에 로컬로 저장되므로, 다른 기기나 다른 브라우저에서는 공유되지 않는다. 이는 의도된 제약이다.

#### Scenario: 새로고침 후에도 완료 상태가 유지된다

- **WHEN** 학습자가 스텝 3개를 완료 표시한 뒤 페이지를 새로고침한다
- **THEN** 그 3개가 여전히 완료 상태로 표시된다

#### Scenario: 완료 표시를 해제한다

- **WHEN** 학습자가 이미 완료 표시된 체크 단위를 다시 활성화한다
- **THEN** 해당 항목이 미완료로 돌아가고 진행률 집계가 1 감소한다

#### Scenario: 로그인 없이 동작한다

- **WHEN** 인증되지 않은 방문자가 체크 단위를 완료 표시한다
- **THEN** 로그인 요구 없이 즉시 기록되고 유지된다

### Requirement: 진행률 집계 표시

시스템은 각 챕터에 대해 "완료 수 / 전체 수" 형태의 진행률을 표시해야 한다(SHALL). 체크 단위의 상태가 바뀌면 해당 챕터의 집계와 학습 경로 화면의 표시가 즉시 갱신되어야 한다(MUST).

#### Scenario: 챕터 카운터가 즉시 갱신된다

- **WHEN** 학습자가 3개 스텝짜리 챕터에서 스텝 하나를 완료 표시한다
- **THEN** 해당 챕터의 카운터가 `0/3`에서 `1/3`으로 즉시 바뀐다

#### Scenario: 챕터를 모두 완료하면 완료 상태로 구분된다

- **WHEN** 챕터의 모든 체크 단위가 완료된다
- **THEN** 해당 챕터의 카운터가 미완료 상태와 시각적으로 구분되는 완료 표현으로 바뀐다

#### Scenario: 학습 경로 화면에 진행 상황이 반영된다

- **WHEN** 학습자가 가이드 상세에서 한 챕터를 모두 완료한 뒤 학습 경로 화면으로 이동한다
- **THEN** 해당 챕터에 해당하는 단계가 완료로 표시된다

### Requirement: 첫 페인트 전 상태 반영

시스템은 보존된 완료 상태를 화면이 처음 그려지기 전에 반영해야 한다(SHALL). 미완료 상태가 먼저 보였다가 완료 상태로 바뀌는 깜빡임이 있어서는 안 된다(MUST NOT). 서버 렌더 결과와 브라우저 상태의 차이로 인한 hydration 오류를 발생시켜서는 안 된다(MUST NOT).

#### Scenario: 진행 상황이 있는 상태로 재방문한다

- **WHEN** 이미 8개 중 3개를 완료한 학습자가 가이드 상세 페이지를 새로 연다
- **THEN** 첫 화면부터 완료한 수가 반영된 채로 그려지며, `0/N`이 잠깐 보였다 바뀌는 현상이 없다

#### Scenario: 콘솔에 hydration 경고가 없다

- **WHEN** 보존된 진행 상황이 있는 상태로 페이지를 로드한다
- **THEN** 브라우저 콘솔에 hydration 불일치 경고가 출력되지 않는다

### Requirement: 탭 간 동기화

같은 브라우저에서 사이트를 여러 탭에 열어둔 경우, 한 탭에서의 완료 상태 변경이 다른 탭에도 반영되어야 한다(SHALL).

#### Scenario: 다른 탭의 변경이 반영된다

- **WHEN** 학습자가 탭 A에서 스텝을 완료 표시하고 탭 B로 전환한다
- **THEN** 탭 B의 해당 스텝과 진행률 카운터가 새로고침 없이 갱신되어 있다

### Requirement: 저장소 장애 시 동작 유지

브라우저 저장소를 사용할 수 없거나(비공개 모드 제한, 용량 초과) 저장된 값이 손상된 경우에도, 시스템은 예외로 화면을 중단시켜서는 안 된다(MUST NOT). 이 경우 진행 상황이 보존되지 않을 뿐 튜토리얼 내용은 정상적으로 열람 가능해야 한다(SHALL).

#### Scenario: 저장된 값이 손상되어 있다

- **WHEN** 브라우저에 저장된 진행 상황 값이 읽을 수 없는 형식이다
- **THEN** 페이지는 빈 진행 상황으로 정상 렌더되고 오류 화면을 보이지 않는다

#### Scenario: 저장소 쓰기가 차단되어 있다

- **WHEN** 저장소 쓰기가 차단된 환경에서 학습자가 완료 표시를 시도한다
- **THEN** 화면은 계속 사용 가능한 상태로 남고 페이지가 깨지지 않는다
