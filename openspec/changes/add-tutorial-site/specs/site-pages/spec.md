## Purpose

사이트를 구성하는 세 화면 — 랜딩, 학습 경로, 가이드 상세 — 의 역할과 화면 간 이동 규칙을 정의한다. 방문자가 처음 도착해서 튜토리얼을 시작하고, 중단했다 돌아와 이어가는 경로를 보장한다.

## ADDED Requirements

### Requirement: 랜딩 화면

시스템은 사이트 루트에 진입 화면을 제공해야 한다(SHALL). 랜딩은 사이트가 무엇인지 한눈에 전달하고 학습 경로로 이동하는 주 액션을 제공해야 한다(MUST). 마케팅 요소(가격표, 후기, FAQ)를 포함하지 않는다.

#### Scenario: 방문자가 루트에 도착한다

- **WHEN** 방문자가 사이트 루트를 연다
- **THEN** 브랜드 워드마크, 한 줄 헤드라인, 짧은 설명, 학습 경로로 가는 주 액션이 보인다

#### Scenario: 랜딩에서 학습을 시작한다

- **WHEN** 방문자가 랜딩의 주 액션을 활성화한다
- **THEN** 학습 경로 화면으로 이동한다

### Requirement: 학습 경로 화면

시스템은 튜토리얼의 챕터를 순서가 있는 단계형 수직 목록으로 보여주는 화면을 제공해야 한다(SHALL). 각 단계는 완료 여부를 표시하고, 활성화하면 가이드 상세의 해당 챕터로 이동해야 한다(MUST).

#### Scenario: 학습 경로에 챕터가 순서대로 나열된다

- **WHEN** 방문자가 학습 경로 화면을 연다
- **THEN** 튜토리얼의 챕터들이 선언 순서대로 번호가 매겨진 수직 목록으로 표시된다

#### Scenario: 단계에서 상세로 이동한다

- **WHEN** 방문자가 학습 경로의 두 번째 단계를 활성화한다
- **THEN** 가이드 상세로 이동하고 해당 챕터가 펼쳐진 상태로 보이며 화면이 그 위치로 스크롤된다

#### Scenario: 완료한 단계가 구분된다

- **WHEN** 한 챕터를 모두 완료한 학습자가 학습 경로 화면을 연다
- **THEN** 해당 단계가 완료로 표시되어 남은 단계와 구분된다

### Requirement: 가이드 상세 화면

시스템은 가이드별 상세 화면을 제공해야 한다(SHALL). 상세 화면은 가이드 제목과 요약, 챕터 아코디언, 각 챕터의 진행률, 스텝별 본문과 명령어를 포함해야 한다(MUST). 영상 임베드나 영상 시청 유도 요소를 포함해서는 안 된다(MUST NOT).

#### Scenario: 가이드 상세를 처음 연다

- **WHEN** 진행 이력이 없는 방문자가 가이드 상세를 연다
- **THEN** 가이드 제목·요약과 함께 챕터들이 접힌 상태로 나열되고, 각 챕터에 `0/N` 진행률이 표시된다

#### Scenario: 챕터를 펼쳐 스텝을 확인한다

- **WHEN** 학습자가 챕터를 펼친다
- **THEN** 해당 챕터의 스텝들이 완료 표시 컨트롤과 함께 나타나고, 스텝을 펼치면 본문과 명령어가 보인다

#### Scenario: 여러 챕터를 동시에 펼친다

- **WHEN** 학습자가 첫 챕터를 펼친 상태에서 두 번째 챕터를 펼친다
- **THEN** 두 챕터 모두 펼쳐진 상태로 유지된다

### Requirement: 챕터 딥링크

가이드 상세의 각 챕터는 주소로 직접 가리킬 수 있어야 한다(SHALL). 챕터를 가리키는 주소로 진입하면 해당 챕터가 펼쳐진 상태로 표시되어야 한다(MUST).

#### Scenario: 챕터 주소로 직접 진입한다

- **WHEN** 방문자가 특정 챕터를 가리키는 주소를 브라우저에 직접 입력해 진입한다
- **THEN** 가이드 상세가 열리면서 해당 챕터가 펼쳐지고 그 위치로 스크롤된다

### Requirement: 가이드 내 목차

가이드 상세는 챕터 목록을 보여주는 보조 목차를 제공해야 한다(SHALL). 목차 항목은 각 챕터의 진행 상황을 표시하고, 활성화하면 해당 챕터로 이동시켜야 한다(MUST).

#### Scenario: 목차로 챕터를 이동한다

- **WHEN** 학습자가 목차의 세 번째 항목을 활성화한다
- **THEN** 해당 챕터가 펼쳐지고 화면이 그 위치로 이동한다

### Requirement: 다음 단계 유도

가이드 상세의 끝에는 학습자가 이어서 할 일을 제시하는 영역이 있어야 한다(SHALL). 이어질 가이드가 없는 경우에도 화면이 어색하게 끝나서는 안 된다(MUST NOT).

#### Scenario: 이어질 가이드가 없다

- **WHEN** 학습자가 마지막 가이드의 끝까지 스크롤한다
- **THEN** 깨진 링크나 빈 카드가 아니라, 이어질 내용이 아직 없음을 알리는 마무리 영역이 표시된다

### Requirement: 전역 내비게이션

모든 화면은 브랜드 워드마크와 학습 경로로 돌아가는 수단을 제공해야 한다(SHALL).

#### Scenario: 가이드 상세에서 학습 경로로 돌아간다

- **WHEN** 학습자가 가이드 상세에서 상단의 되돌아가기 수단을 활성화한다
- **THEN** 학습 경로 화면으로 이동하고, 기록된 진행 상황이 그대로 반영되어 보인다
