## Purpose

튜토리얼 콘텐츠의 구조와 유효성 규칙을 정의한다. 챕터·스텝·명령어의 데이터 모델을 고정해, 콘텐츠를 추가하거나 수정할 때 화면 코드를 건드리지 않아도 목차·진행률·내비게이션이 따라오게 한다.

## ADDED Requirements

### Requirement: 콘텐츠 계층 구조

시스템은 튜토리얼 콘텐츠를 가이드 → 챕터 → 스텝의 3단계 계층으로 표현해야 한다(SHALL). 각 가이드는 하나 이상의 챕터를 가지며, 각 챕터는 0개 이상의 스텝을 가진다. 가이드·챕터·스텝은 각각 사람이 읽을 수 있는 제목과, 해당 가이드 안에서 유일한 식별자를 가져야 한다(MUST).

#### Scenario: 챕터와 스텝이 정의된 순서대로 노출된다

- **WHEN** 가이드가 3개의 챕터를 순서대로 선언하고 첫 챕터가 3개의 스텝을 선언한 상태에서 학습자가 가이드 상세를 연다
- **THEN** 챕터는 선언된 순서대로 1, 2, 3번으로 번호가 매겨져 표시되고, 첫 챕터를 펼치면 스텝 3개가 선언 순서대로 나타난다

#### Scenario: 스텝 식별자가 중복되면 거부된다

- **WHEN** 한 가이드 안에서 두 스텝이 같은 식별자를 사용한다
- **THEN** 콘텐츠 검증이 실패하고 어느 식별자가 중복되었는지 알리는 오류가 발생한다

### Requirement: 체크 단위 정규화

시스템은 학습자가 완료 표시할 수 있는 단위를 "체크 단위"로 정의해야 한다(SHALL). 스텝이 있는 챕터에서는 각 스텝이 체크 단위가 된다. **하위 스텝이 없는 챕터는 그 챕터 자체가 하나의 체크 단위**가 되며, 전체 진행률 집계에 포함되어야 한다(MUST).

이 요구는 콘텐츠 계층의 일반 규칙이다. 첫 가이드는 검토 결과 모든 챕터가 스텝을 갖게 되어 이 경로를 쓰지 않지만, 규칙 자체는 계층의 계약으로 남는다.

#### Scenario: 스텝이 없는 챕터가 진행률에 포함된다

- **WHEN** 가이드가 스텝 3개짜리 챕터, 스텝 2개짜리 챕터, 스텝이 없는 챕터로 구성된다
- **THEN** 전체 체크 단위는 6개로 집계되고, 스텝이 없는 챕터는 중첩 목록 없이 챕터 헤더 자체에 완료 표시 컨트롤을 노출한다

#### Scenario: 스텝 없는 챕터를 완료 표시한다

- **WHEN** 학습자가 스텝이 없는 챕터의 완료 표시 컨트롤을 활성화한다
- **THEN** 해당 챕터가 완료로 기록되고 전체 진행률이 1 증가한다

### Requirement: 스텝 본문과 명령어

각 스텝은 서식 있는 본문을 가져야 하며(SHALL), 0개 이상의 터미널 명령어를 선언할 수 있다(MAY). 각 명령어는 실행할 명령 문자열을 가지며, 선택적으로 설명을 덧붙일 수 있다.

#### Scenario: 명령어가 복사 가능한 형태로 노출된다

- **WHEN** 스텝이 명령어 2개를 선언하고 학습자가 그 스텝을 펼친다
- **THEN** 명령어 2개가 각각 고정폭 서체로, 개별 복사 컨트롤과 함께 표시된다

#### Scenario: 빈 명령어는 거부된다

- **WHEN** 스텝이 빈 문자열이거나 공백뿐인 명령어를 선언한다
- **THEN** 콘텐츠 검증이 실패한다

### Requirement: 콘텐츠 검증

시스템은 콘텐츠 구조를 빌드 시점에 검증해야 한다(SHALL). 검증에 실패하면 빌드가 성공해서는 안 된다(MUST NOT). 검증은 최소한 다음을 포함한다: 가이드 내 식별자 중복, 선언된 스텝에 대응하는 본문의 부재, 빈 명령어, 존재하지 않는 가이드를 가리키는 참조.

#### Scenario: 본문이 없는 스텝은 빌드를 실패시킨다

- **WHEN** 구조에는 선언되어 있으나 대응하는 본문이 없는 스텝이 존재한다
- **THEN** 빌드가 실패하고 어느 가이드의 어느 스텝인지 식별할 수 있는 오류 메시지가 출력된다

#### Scenario: 잘못된 참조는 빌드를 실패시킨다

- **WHEN** 가이드가 등록되지 않은 가이드를 다음 단계로 참조한다
- **THEN** 빌드가 실패한다

### Requirement: 가이드 사전 렌더링

시스템은 등록된 모든 가이드를 빌드 시점에 정적으로 렌더링해야 한다(SHALL). 등록되지 않은 식별자로 접근하면 404를 반환해야 한다(MUST).

#### Scenario: 등록되지 않은 가이드 주소로 접근한다

- **WHEN** 학습자가 존재하지 않는 가이드 식별자가 담긴 주소를 연다
- **THEN** 404 응답을 받는다
